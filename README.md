Experiment-2 CHARACTERISTICS OF CE CONFIGURATION
Aim:
To Plot the input and output characteristics of the transistor in CE mode, to determine the h-parameters from the graph.

Components Required:
image # Procedure: INPUT CHARACTERISTICS 1. Connections are made as per the circuit diagram.
VCE is kept const (say 5v), VBE is varied insteps of 0.1v and the corresponding IB values are tabulated.

The above procedure is repeated for different constant values.

Graph is plotted between VBE and IB for a constant VCE

The h – parameter values are found from the graph.

OUTPUT CHARACTERISTICS

Connection are made as per the circuit diagram
IB is kept const, VCE is varied in step of 1V, the corresponding IC values are tabulated. The above procedure is repeated for different IB constant values.
Graph is plotted between VCE and Ic for a constant IB.
The h – parameter values are found from the graph.
